# Song Recommendation System Based on Moods

This project is a machine learning-based recommendation system that suggests songs based on the user's mood. It analyzes mood based on our face and returns a curated list of songs that best match the identified emotion.

## Project Overview

The goal of this system is to create a personalized music experience by connecting the user's emotional state with relevant songs. It can be useful in applications such as music players, mental health platforms, or social media integrations.

## Features

- Detect user mood from real time face by camera
- Recommend songs matching the detected emotion
- Support for multiple moods (happy, sad, energetic, calm, etc.)
- Clean and modular architecture for easy customization
- Optional integration with Spotify API or local music dataset
